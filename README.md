## Featured projects

### 🛡️ [OpenFinGuard](https://github.com/Pranavi0525/OpenFinGaurd): AI Credit Intelligence Platform
Production-patterned credit risk system on 150K borrowers (Give Me Some Credit).
- Gradient Boosting champion model, **AUC-ROC 0.86**, KS 0.51, inference under 10 ms
- **SHAP** explanations on every prediction (ECOA adverse-action style reasons)
- **Fairness audit** using the 80% rule across age, income and dependents
- FastAPI + PostgreSQL audit trail + Streamlit dashboard, fully Dockerized

`Python` `FastAPI` `scikit-learn` `SHAP` `PostgreSQL` `Docker` `Streamlit` `MLflow`

### 🏦 [CreditSafe](https://github.com/Pranavi0525/Credit_Risk_System): Loan Default Prediction App
End-to-end XGBoost web app with an applicant mode (instant risk score, auto-generated offer or appeal letter) and a password-protected manager dashboard with live KPIs, charts and CSV export. Applications are logged to Google Sheets.
**[Live demo](https://creditrisksystem-2i4vpzd3mgyisouna38rbg.streamlit.app/)**

`Python` `XGBoost` `Streamlit` `Google Sheets API`

### 🛒 Discovery Agent: Trust-Based Autonomous Shopping Agent
Team project: a shopping agent with a Gemini planner, LangGraph executor and Shopify MCP, with a Streamlit UI. I worked on the safety layer: prompt-injection input guard (rules + Llama Prompt Guard 2), request dedup, and rate limiting.

`Python` `LangGraph` `Gemini` `MCP` `Streamlit`
